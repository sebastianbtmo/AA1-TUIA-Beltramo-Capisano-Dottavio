## Requisitos e Instalación

### 1. Clonar el repositorio
```bash
git clone https://github.com/sebastianbtmo/AA1-TUIA-Beltramo-Capisano-Dottavio.git
cd AA1-TUIA-Beltramo-Capisano-Dottavio
```

### 2. Crear y activar un entorno virtual (Recomendado)
* **En Windows:**
  ```bash
  python -m venv venv
  .\venv\Scripts\activate
  ```
* **En Linux / macOS:**
  ```bash
  python3 -m venv venv
  source venv/bin/activate
  ```

### 3. Instalar dependencias
```bash
pip install -r requirements.txt
```

## Guía de Uso

1. Abre la carpeta del proyecto en **VS Code** con la extensión de Jupyter instalada.

2. Navega a la carpeta `TP_2/` y abre el archivo **`TP_clasificacion_AA1.ipynb`**.

3. Ejecuta las celdas secuencialmente.
